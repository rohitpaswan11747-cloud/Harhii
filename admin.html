4 आसान स्टेप

① नीचे product चुनें या नया बनाएँ → ② नाम, फोटो और कीमत भरें → ③ Save Product फिर Download products.json दबाएँ → ④ GitHub में products.json खोलकर Pencil (Edit) पर जाएँ; डाउनलोड हुई JSON का पूरा text paste करें और Commit changes करें। Website refresh करें।
